# Vyapaar AI

### AI-Powered Merchant Growth Platform

Vyapaar AI is an AI-powered platform that helps small businesses understand their transaction patterns, identify growth opportunities, and generate actionable business recommendations.

## ✨ Features

- 📊 **Business Health Analysis** – Understand sales and transaction performance.
- 📈 **Hourly Sales Analysis** – Identify low-activity periods from transaction patterns.
- 🤖 **AI Recommendations** – Generate business-specific growth suggestions using Sarvam AI.
- ⚡ **Growth Action Activation** – Approve and activate recommended actions.
- 📉 **Performance Monitoring** – View simulated results of activated growth actions.
- 🏪 **Multi-Business Support** – Analyze multiple businesses independently.

🚀 Getting Started
Clone the repository
git clone https://github.com/ritikasingh2509/Vyapaar-AI.git
cd Vyapaar-AI
Install dependencies
cd backend
npm install
Configure environment variables

Create a .env file inside the backend folder:

MONGODB_URI=your_mongodb_connection_string
SARVAM_API_KEY=your_sarvam_api_key
Start the backend
node server.js

Backend runs on:

http://localhost:5001

Then open frontend/index.html in your browser.

📊 Data

The project uses synthetic transaction data for demonstration purposes. Campaign performance shown in the prototype is simulated and does not represent real-world results.
